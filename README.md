# Alignements

Déplace une bille par un chemin libre pour aligner cinq billes de la même couleur. Sinon, trois nouvelles billes tombent sur le plateau.

Sur un plateau de 9 × 9, chaque déplacement qui ne fait pas de ligne amène trois billes de plus. Une ligne de cinq ou plus disparaît. La partie s'arrête quand le plateau est plein.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Alignements → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
